App Overview & Key Features

This interactive playground lets you visually build, experiment with, and master CSS Grid layouts in real time. Configure row and column tracks, drag across cells to merge grid regions, and instantly copy clean, boilerplate code HTML and CSS code for your projects.

  • Interactive Layout Designer: Configure up to 12 rows and columns with custom gaps, then drag across adjacent cells to merge them into custom layout regions.
  • Rapid Wireframing: Prototype complex dashboard views, image galleries, landing page content blocks, and app layouts without writing code by hand.
  • Real-Time Code Generator: Instantly view and export generated HTML markup and CSS stylesheets.

How to Use

  • 1. Set Dimensions: Adjust columns, rows, and gap in the left panel.
  • 2. Set Output Scaling: Check "Scale to Entire Page" for full viewport generation or specify custom width/height values.
  • 3. Merge Cells: Click and drag across adjacent tiles in the viewport to combine them.
  • 4. Export Code: Click the copy button in the panel headers to get your generated HTML and CSS.

Fundamental Concepts: Understanding display: grid

Applying display: grid turns an element into a two-dimensional layout container. Unlike standard block elements or one-dimensional Flexbox containers, CSS Grid provides total control over both horizontal columns and vertical rows simultaneously.

1. Grid Container & Tracks

The direct outer parent element acts as the Grid Container. Structural tracks and gutters are defined using structural container properties:

  • grid-template-columns: Sets the width and total number of column tracks (e.g., repeat(5, 1fr)).
  • grid-template-rows: Defines the height and total number of row tracks.
  • gap: Specifies explicit gutter spacing between grid tracks without adding extra margin to the outer edges.

2. Grid Items & Coordinate Positioning

Direct children automatically become Grid Items placed along invisible coordinate lines:

  • Grid Lines: Numbered index lines (starting at 1) that delineate track boundaries.
  • grid-column / grid-row: Defines where an item begins and how many tracks it spans across (e.g., grid-column: 2 / span 3).
  • Cell Engulfment: When an item spans multiple cells, it occupies those intersections and visually covers the underlying tracks.
